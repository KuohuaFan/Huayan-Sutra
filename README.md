## 部署

### 方式一：分片版（推薦，桌機操作）

整包內容置於倉庫根目錄：

    git add index.html index-standalone.html text/ extract.py README.md
    git commit -m "華嚴經讀本 v1.3"
    git push

隨後於 Settings → Pages，Source 選 `main` 分支、`/ (root)`。

**目錄結構不可更動。** `index.html` 以相對路徑 `./text/…` 載入語料。
首屏僅取當前一卷，最大單一分片不足四十千位元組。

若僅上傳 `index.html` 而未上傳 `text/` 目錄，全品將顯示「語料未載入」。
此為部署問題，非經文缺漏，站內已內建該項診斷訊息並列出預期路徑。

### 方式二：單檔版（手機操作）

GitHub 網頁版在行動裝置上無法保留資料夾結構，八十三個分片不可能逐一建立路徑。
此時改用單檔版：

1. 將 `index-standalone.html` **改名為 `index.html`**
2. 於倉庫上傳頁（`github.com/<帳號>/<倉庫>/upload/main`）上傳這一個檔
3. Settings → Pages，Source 選 `main` 分支、`/ (root)`

功能與分片版完全一致，唯首次載入約 2.3 MB。

兩版可並存：`index.html` 走分片，另存一份 `standalone.html` 作離線備份。

### 部署後須改的字串

`index.html` 開頭的 `<link rel="canonical">` 與 `og:url` 目前寫作
`https://kuohuafan.github.io/Avatamsaka-Sutra/`。
倉庫名若非 `Avatamsaka-Sutra`，須一併改為實際位址。
此僅影響搜尋引擎與分享預覽，不影響網站運作，可先上線再改。

## 結構

節點分四層：**會 — 品 — 參 — 段**。

會為主軸，說法之處有七，集會之次有九，普光明殿三度集會，故處七而會九。
科判採澄觀《華嚴經疏》四分五周因果，分與周並列為兩套刻度而不折疊為一——
華嚴之會與周不整齊嵌套，此與《法華經》二門六段構成正交格者不同。

分節單位為卷而非品。八十華嚴品長懸殊，〈入法界品〉獨佔二十一卷，
字數超過整部《法華經》兩倍有餘，若沿用一品一頁之體例將無法閱讀。
該品復於卷層之下再開參層，是全站唯一的四層節點。

## 語料

自 CBETA XML TEI-P5 官方倉庫 `cbeta-org/xml-p5`（檔案 `T/T10/T10n0279.xml`）
以 `extract.py` 機械轉出，未經人工改字：

- 異文取 `lem` 而捨 `rdg`
- 校記 `note`、行頁標記 `lb`／`pb`、錨點 `anchor` 悉數剔除
- 缺字依原檔 `charDecl` 還原為 Unicode，全檔零未解缺字、零殘留標記
- 偈頌之 `caesura` 轉全形空格，`l` 元素轉斷行
- 卷次依 `cb:juan` 開合標記切分，品次依 `cb:div type="pin"` 文件順序判定

底本更新時重跑 `extract.py` 即可，人工不介入。相依套件僅 `lxml`。

語料狀態由 `text/manifest.js` 實算，而清單與分片由同一程式同時產出，
故目錄所示狀態不可能與磁碟實況背離。

字數以 Python 計，一字為一 Unicode 字元。瀏覽器端以 UTF-16 碼元計時，
基本平面外之罕用字會計為二，故 JavaScript 重算約多二十五字。
此為計數單位差異，非語料差異。

## 五十三參分節

分節以程式自經文偵測，不依後世通行的參次表填入。
偵測依據為經文自身的轉介語：每位善知識說法既畢，
皆以「有〔身分〕名〔某〕。汝詣彼問」之形式指出下一位，
以此為界，其後第一段（善財辭退南行、抵達次一善知識之敘事）即為該參起點。

驗算結果：五十三參次，另加彌勒指回文殊之「重見」一節（同一人，不別立參次），
共五十四節；段覆蓋 1233 / 1233，字覆蓋 198325 / 198325，起點嚴格遞增。

偵測過程中兩點須說明。其一，轉介語有句式變體：〈遍友〉指向〈善知眾藝〉時作
「汝可問之」而非「汝詣彼問」，若僅以標準句式偵測，此參會整個漏失，
而總數仍會湊成看似合理的數字。其二，偈頌中會重述前一位善知識之名，
形成假轉介，須以連續同名去重排除。

身分稱謂一律照錄經文本身用字。例如彌伽經文作「有人，名曰：彌伽」，
本站即記為「人」，不改寫為後世通稱之「長者」或「語言法師」；
大天與妙德圓滿經文作「神」，亦不逕改為「主夜神」。
通稱多出於註疏傳統，未必是譯本原文，兩者不宜在同一欄位混用。

## 自撰層

品旨語譯與要義提點存於 `text/gloss.js`，合計約一萬三千六百字。

**此為提要式品旨語譯，非逐句對譯。** 所述為一品之綱領、說主、所答之問與所立之門，
供入品之前先得梗概。全經六十八萬九千餘字的逐句白話對譯非本讀本所承擔，
亦非閱讀所必需。細部義理仍應依經文與歷代註疏。

自撰層所引經句一律取自本站已校錄之八十本原文，經程式比對確認，不採二手轉述。
其中三處常見誤引已於文內標明區辨：

- 〈梵行品〉八十本作「初發心時即得阿耨多羅三藐三菩提」，
  習見之「初發心時便成正覺」為六十本語。
- 〈普賢行品〉經文限定為「若諸菩薩於**餘菩薩**起瞋恚心，即成就百萬障門」，
  所戒者為對同行菩薩之瞋，泛引作一切瞋心者失其限定。
- 「應觀法界性，一切唯心造」出於第二十〈夜摩宮中偈讚品〉覺林菩薩偈，
  全經僅此一見，引用時應繫品而不宜泛稱出自《華嚴經》。

## 版本註記

品層設版本註記欄位共十六則，涵蓋六十華嚴（T09 no.278，三十四品、七處八會）、
八十華嚴（T10 no.279）、四十華嚴（T10 no.293）三譯本之異同。要者如下：

- 〈十定品〉為八十本所增，六十本無，兩本遂由八會三十四品成九會三十九品，
  此為兩本結構差異之樞紐。
- 〈如來出現品〉六十本作〈寶王如來性起品〉，華嚴宗「性起」一語即本於舊譯品名。
- 〈普賢行願品〉出自四十華嚴末卷，八十本並無獨立流通分，
  通行讀本取之補足係後世組合，非實叉難陀原譯本結構。
- 第三十一品原檔品題作〈壽量品〉，並無「如來」二字；
  《法華經》第十六〈如來壽量品〉為另經，名近而旨異。

品名與卷次已全數以 CBETA 原檔卷首品題比對更正。
其中〈壽量品第三十一〉品名與〈昇兜率天宮品〉卷次兩處為初版之誤，
已修正並留註於站內。

## 朗讀

以瀏覽器內建語音合成朗讀，朗讀範圍為**畫面當前顯示之卷或參**，非整品。
經文依句讀切為短句依序播放，全經共約一萬七千九百句，單句上限一百一十字；
偈頌自動對齊四句一偈。播放中右下角顯示進度句數。

v1.3 修正三項缺陷。其一，原程式對跨卷之品取全品文字，但未載入之卷靜默略過，
實際只讀到當前一卷——〈十迴向品〉僅百分之十，〈離世間品〉僅百分之十三。
今渲染與朗讀共用同一取材函式，畫面所見即朗讀所讀。
其二，原程式將整段文字作為單一 utterance 送出，最長逾十九萬字，
各家瀏覽器對單一 utterance 長度與連續播放時間皆有上限，必被截斷。
其三，未指定語音、無保活機制。今明確挑選 zh-TW 語音，
並以定時 pause/resume 迴避 Chrome 長時間播放後自行暫停之行為；
單句失敗跳過續播，連續五句失敗才中止。

行動裝置須先解除靜音並允許網頁播放聲音。若系統未安裝中文語音，
朗讀會失敗或以外語音色讀出，此為作業系統層級設定，非本站可控。

## 經義問答

全螢幕、無氣泡的語錄式版面。左上工具列提供紀錄、收藏、專案、新增、刪除。
對話存於使用者本機，不上傳：優先使用 `window.storage`（沙箱環境），
其次 `localStorage`（靜態部署），皆不可用時退為僅此工作階段有效的記憶體儲存。
畫面上會直接標示目前落在哪一段。

瀏覽器會因跨來源政策或缺少憑證而被擋下，須自建代理端點並修改該常數。
失敗時畫面會明確說明成因與所需動作，不吞成籠統訊息。
經文、語譯、要義、各層索引均不受影響。
